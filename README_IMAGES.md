## Instructions
1. Get the images (from your designer or stock photos).
2. Rename them **exactly** as listed above (make sure extension matches, e.g., if you have `.jpg` change the code or convert to `.png` as requested, or just update the code to match your file).
3. Drop them into the `public/images/portfolio` folder.
4. Refresh the page!
